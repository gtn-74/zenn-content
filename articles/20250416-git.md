## はじめに
ブランチを消すことがルーティン化していないと、気づいたらブランチが大量に溜まっていることに後から気がつきます。

`git branch -d ブランチ名`コマンドでブランチを1ずつ削除する方法だったり、GithubのGUIでリモートブランチを削除。
