## まとめる

- **スケールアップ**：サーバーの性能を上げる
- **スケールダウン**：サーバーの性能を下げる

---

- **スケールアウト**：サーバーの台数を増やす
- **スケールイン**：サーバーの台数を減らす

---

- **アンマネージドサービス**：素のサーバーだけをレンタルする
- **マネージドサービス**：バックアップや運用保全などを AWS 側のサービスを利用することで亜ンマネージドサービスでは、自身で管理しなければいけないことも、サービスで対応できる

**マネージドサービス注意**

マネージドサービスは、AWS が運用管理しているため、最新の環境に更新される。そのため新しいバージョンと、古いバージョンの二重管理したいといった要望に応えることが難しかったりする様子。

- **可用性**：システムが使える時間／稼働時間

メンテナンスを考慮すると 100%の可用性は難しい。

可用性は、SLA に記されている。

- `1ヶ月（43,200分）* (100 - 99.9) = 7.2h(432m)`
- `1ヶ月（43,200分）* (100 - 99.99) = 43.2m`

もしサービスを無停止で運用しなければいけない場合、システムを冗長化する仕組みが必要。

- **リージョン**：世界 32 カ国で展開されている地域のこと

AWS 利用者は、好きなリージョンに仮想サーバー、仮想ネットを構築、運用できる。

でも、ユーザーから近いリージョンである方が、通信のレスポンスが速い。

AWS を利用する場合によく用いられるサービスは多くても 10 サービス程とのこと。

| サービス    | アンマネージドサービス／マネージドサービス | 概要                                                             |
| ----------- | ------------------------------------------ | ---------------------------------------------------------------- |
| IAM         | -                                          | ユーザーグループ管理、認証                                       |
| VPC         | アンマネージドサービス                     | 仮想ネットワーク                                                 |
| Elastic IP  | アンマネージドサービス                     | 固定 IP アドレスを割り当て                                       |
| EC2         | アンマネージドサービス                     | 仮想サーバー                                                     |
| EBS         | アンマネージドサービス                     | 仮想サーバーで使うストレージ                                     |
| S3          | マネージドサービス                         | Web サーバーとして使えるストレージサービス。                     |
| RDS         | マネージドサービス                         | データベース                                                     |
| Route 53    | マネージドサービス                         | DNS                                                              |
| Cloud Front | マネージドサービス                         | web コンテンツキャッシュ機能を提供、HTTPS で暗号通通信機能も     |
| ELB         | マネージドサービス                         | 複数台の EC2（仮想サーバーに負荷分散する、HTTPS で暗号通信機能） |

AWS は従量課金のため、運用予算を試算することが難しい。

試算するために下のコスト計算ツールが提供されている。

[AWS Pricing Calculator](https://calculator.aws/#/)

サービス管理はリージョン単位。大阪リージョンでは提供されていないサービスを東京リージョンでは持ってたりする。

ダッシュボードは、サービス単位で持っている。

**リソース**：AWS 上で扱うサービスの総称
**アクション**：AWS 上の操作
**ポリシー**：アクションをグループ化したモノ

**ルートユーザー**：コンソールマネージャーを作った人、請求、金銭関連はルートユーザーだけが設定できる
